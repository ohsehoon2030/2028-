영등포구을 가상 개표방송 — 시제품 02

사용 방법
1. ZIP 전체를 압축 해제합니다.
2. index.html을 Chrome 또는 Edge 등 최신 브라우저에서 엽니다.
3. 방송 시작을 누르거나 기준 시각 버튼을 눌러 이동합니다.
4. GitHub Pages에서는 기존 총선 시뮬레이터와 별도의 폴더(예: broadcast)에 파일 구조를 그대로 업로드하세요.
   vendor 폴더, app.js, model.js, style.css를 함께 올려야 합니다.

설정
- 서울 영등포구을 / 합산 PVI 국힘+3.8 / 전국 양 진영 50:50
- 최종 민주 46.2%, 국힘 53.8%
- 20:17 시작 ~ 다음 날 02:00 종료
- 기본 1배속: 실제 1초 = 가상 1분, 전체 5분 43초
- 방송 시계는 1분 단위, 투표함 집계는 13~16분 간격의 23회
- 2024 후보명을 사용하는 가상 방송이며 실제 방송 재현이 아닙니다.

추정 원칙
사용자가 제공한 4개 근사 관측점에서 민주 득표율을 4.0%p 낮추고 국힘을 그만큼 높였습니다.
과거 기타 후보 득표를 별도로 복원하지 않은 양자 단순화입니다.
관측점 사이에는 누적 득표수를 보간합니다. 정수 득표수는 감소하지 않습니다.
총 98,945표는 기존 2024 영등포구을 자료의 유효표 규모를 차용했습니다.
당선 확정은 남은 모든 표를 2위에게 주더라도 역전할 수 없을 때 표시합니다.

구현
- PixiJS 8.22.0 / WebGL 그래프, GPU 사용이 불가능하면 Canvas 2D 호환 모드
- 그래프의 연속 렌더링을 중지하고 집계·창 크기 변경 시에만 렌더링
- 화면 해상도 배율 최대 1.5, 다른 탭 이동 시 자동 일시정지
- 사용자 제공 후보 사진 2장 포함. 동영상, 외부 폰트, 외부 데이터 요청 없음
- PixiJS 배포본과 MIT 라이선스 포함
  https://pixijs.com/
  https://github.com/pixijs/pixijs

검증 범위
모델과 재생 로직은 Node 기반 모의 DOM/그래픽 엔진으로 검사했습니다.
실제 브라우저 렌더링, 휴대폰 GPU 성능은 아직 검증하지 않았습니다.

사진 업데이트: assets 폴더를 포함해 전체 파일을 기존 broadcast 폴더에 업로드하세요. 사진 원본은 변형하지 않았습니다.
